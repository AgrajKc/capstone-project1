# WHY

**WHY** is a personal debugging and reflection journal.

It helps you understand mistakes by asking four simple questions:

1. What went wrong?
2. Why do you think it happened?
3. And why did that happen?
4. What would you do differently next time?

## Features

* 4-step reflection process
* Save reflections with SQLite
* Memory Book
* Search reflections
* View, edit, and delete reflections
* Responsive design

## Built With

* Python
* Flask
* SQLite
* HTML
* CSS

## How to Run

pip install -r requirements.txt

python app.py

Then open:

http://127.0.0.1:5000
